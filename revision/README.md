# Revision

Condensed revision notes for fast review.

## Purpose

One-page-per-topic summaries for interview preparation, exam revision, and quick refreshers. Revision notes assume the reader has completed the related lesson.

## Conventions

- File naming: `topic-name.md`
- One file per module or major topic
- Only the most essential facts, commands, and patterns
- Every note links to the full lesson it summarizes
- Notes are kept short enough to review in minutes
