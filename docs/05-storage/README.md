# Module 05 - Storage

## Overview

Module 05 covers persistent data. Containers are ephemeral by design, so Kubernetes provides volumes, PersistentVolumes, PersistentVolumeClaims, and StorageClasses for data that must survive restarts.

## Learning Outcomes

After completing this module you will be able to:

- Explain volume types and when to use each
- Bind PersistentVolumes to PersistentVolumeClaims
- Use StorageClasses for dynamic provisioning
- Understand access modes, reclaim policies, and storage patterns
