# Cheat Sheets

Quick-reference cheat sheets.

## Purpose

Fast, printable, command-and-snippet references. Cheat sheets are the last stop before an interview or exam.

## Conventions

- File naming: `topic-cheatsheet.md`
- Commands are grouped by goal, not by syntax
- Include only verified commands with common flags
- YAML snippets are minimal and correct
