# Interview

Interview questions organized by topic.

## Purpose

A dedicated interview preparation section. Questions are mapped to modules so candidates can practice the exact topics that match their study progress.

## Conventions

- File naming: `topic-name.md`
- Every file groups questions by difficulty: beginner, intermediate, advanced
- Each question includes a model answer or a pointer to the lesson that covers it
- Scenario questions are separated from direct questions
- Content is updated as the curriculum evolves
